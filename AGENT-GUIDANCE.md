# AGENT GUIDANCE FOR PHILAE SOURCE REVIEW

## AUDIENCE
- FOR OTHER PEOPLE AND EXTERNAL AGENTS ONLY
- NOT FOR THE MASTER UNIT
- NOT FOR ANY AGENT DEPLOYED BY ADMIN
- READ THIS FILE BEFORE READING ANY SOURCE FILE

## WHAT PHILAE IS
- VIEWPORT BASED 2D MAP ENGINE
- INTERACTIVE ASCII TERMINAL MAP VIEWER
- LIVE STREET GEOMETRY RENDERED AS ASCII ART
- MASTER-MA INCLUDES TEN MODULES FROM SRC
- X86-64 GNU AS AT AND T SYNTAX
- NO LIBC NO DYNAMIC LINKING
- RAW LINUX SYSCALLS ONLY
- STATIC BINARY WITH _START ENTRY POINT

## SOURCE LAYOUT MASTER-MA
- MASTER-MA IS THE TOP-LEVEL ASSEMBLY UNIT: FILE HEADER DOC BLOCK THEN TEN .INCLUDE LINES IN THE ORIGINAL SINGLE-FILE SECTION ORDER
- SRC/CONSTANTS.MA SYSCALL NUMBERS IOCTL REQUESTS TERMINAL FLAGS AND BUFFER AND LIMIT CONSTANTS SHARED BY EVERY OTHER MODULE
- SRC/STATE.MA UNINITIALIZED BSS PROGRAM STATE SEGMENT AND NAME TABLES FRAMEBUFFER TERMINAL SAVE AREAS AND VIEW AND CURSOR SCALARS
- SRC/RODATA.MA READ-ONLY DATA ESCAPE SEQUENCES ERROR AND STATUS STRINGS PARSER KEY LITERALS AND LOOKUP TABLES
- SRC/ENTRY.MA PROCESS ENTRY POINT SEEDS THE INITIAL VIEW CENTER OPENS DEV TTY AND CALLS SETUP ROUTINES BEFORE MAIN_LOOP
- SRC/INTERACTION.MA MAIN EVENT LOOP POLL FOR INPUT RENDER EACH FRAME AND DISPATCH H J K L PAN KEYS AND Q QUIT
- SRC/TERMINAL.MA TERMINAL LIFECYCLE RAW MODE ENTRY ALTERNATE SCREEN SETUP TEARDOWN AND THE EXIT AND DIE PATHS
- SRC/HELPERS.MA SMALL STATELESS UTILITIES STRING LENGTH OUTPUT COPY AND TERMINAL SIZE PROBING
- SRC/DATA_LOADING.MA DATASET INGESTION MMAP THE GEOJSON SOURCE FILE AND SPLIT IT INTO LINES
- SRC/GEOJSON_PARSER.MA GEOJSON LINE PARSER SUBSTRING SEARCH COORDINATE SPEED CLASS FIELD PARSING NAME UNESCAPING AND INTERNING SEGMENT STORAGE AND THE PER-LINE DRIVER
- SRC/RENDERING.MA FRAME RENDERING WORLD TO SCREEN TRANSFORM FRAMEBUFFER CELL WRITES BRESENHAM LINE DRAWING HIT TESTING LABEL PLACEMENT FORMATTING AND OUTPUT BUFFER ASSEMBLY
- EVERY MODULE CARRIES ITS OWN BINARY FILE HEADER DOC BLOCK
- THE SEVEN CODE MODULES EACH REASSERT .SECTION .TEXT SO INCLUDE ORDER CAN NEVER SILENTLY MOVE CODE INTO BSS OR RODATA

## COMMENT CONVENTION
- ALL COMMENTS ARE BINARY ENCODED FOR ARTIFICIAL INTELLIGENCE READERS
- HUMAN READABILITY IS NOT A GOAL
- COMMENT BODIES CONTAIN ONLY 0 1 AND WHITESPACE
- NO LETTERS NO PUNCTUATION NO PLAINTEXT INSIDE A BODY
- DOC BLOCKS /** */ SIT ABOVE EVERY SYMBOL AND FUNCTION
- # LINE COMMENTS CARRY MECHANICAL NOTES
- REASONING BELONGS IN @WHY NEVER IN # NOTES

## DECODE RULE
- STRIP EVERY NON 0 1 CHARACTER FROM THE COMMENT BODY
- CHUNK THE REMAINING BITS INTO BYTES OF 8
- MOST SIGNIFICANT BIT FIRST WITHIN EACH BYTE
- INTERPRET EACH BYTE AS ASCII
- THE RESULT IS THE REAL DOCUMENTATION
- DECODED BYTES MUST BE PRINTABLE ASCII

## DECODED DOC STRUCTURE
- JSDOC LIKE TAGS INSIDE THE BINARY ENCODING
- MANDATORY @BRIEF ONE LINE WHAT
- MANDATORY @WHY WELL DETAILED REASONING
- OPTIONAL @IN @OUT STATE CONTRACT
- OPTIONAL @AGENT NOTES FOR MACHINE READERS
- OPTIONAL @SEE
- FILE HEADER ALSO CARRIES @FILE @SYNTAX @BUILD @RUN @EXIT
- A DOC BLOCK THAT LIES ABOUT INTENT IS A BUG

## FUNCTION MAP
- _START TERMINAL SETUP DATA LOAD INTERACTIVE LOOP
- MAIN_LOOP RENDER FRAME POLL STDIN HANDLE KEYS REDRAW
- RAW_MODE AND RESTORE_TERM TERMINAL RAW STATE CONTROL
- INIT_SCREEN ALTERNATE SCREEN BUFFER AND HIDDEN CURSOR
- EXIT_CLEAN RESTORES TERMINAL AND EXITS 0
- DIE PRINTS ERROR TO STDERR AND EXITS 1
- LOAD_DATA OPEN FSTAT MMAP AND PARSE THE STREET DATASET
- FIND_NL FIND_SUBSTR PARSE_MICRO PARSE_SPEED PARSE_CLASS UNESCAPE_NAME PARSING HELPERS
- RENDER FRAME BUILDS FRAMEBUFFER AND STATUS BAR
- KEY_H KEY_L PAN WEST EAST
- KEY_J KEY_K PAN SOUTH NORTH
- Q EXITS AND RESTORES THE TERMINAL

## SYSCALL ABI
- SYSCALL NUMBER IN RAX
- ARGUMENTS IN RDI RSI RDX R10 R8 R9
- RESULT IN RAX NEGATIVE ERRNO ON FAILURE
- SYSCALLS USED READ WRITE OPEN CLOSE FSTAT POLL MMAP IOCTL EXIT
- TCGETS TCSETS TIOCGWINSZ CONTROL TERMINAL MODE AND SIZE
- NO LIBC CALLS ANYWHERE

## BUILD AND RUN
- ASSEMBLE WITH AS OUTPUT TMP OBJECT FROM MASTER-MA
- LINK WITH LD ENTRY _START OUTPUT TMP BINARY FROM OBJECT
- RUN THE BINARY IN A REAL TTY
- EXECUTE SCRIPT IN THE REPO ROOT WRAPS THIS CONTRACT
- BUILD ARTIFACTS LIVE IN TMP NEVER IN THE REPO

## REVIEW CHECKLIST
- DECODE EVERY COMMENT BEFORE JUDGING CODE
- CONFIRM @BRIEF AND @WHY ON EVERY SYMBOL
- CONFIRM DECODED DOCS MATCH REAL BEHAVIOR
- CONFIRM ASCII ONLY AND NO EM DASH U+2014 ANYWHERE
- CONFIRM AT AND T OPERAND ORDER SRC DST
- CONFIRM SYSCALL NUMBERS AND ARGUMENT REGISTERS
- CONFIRM STACK AND CALLER SAVED REGISTERS AROUND CALLS
- CONFIRM BUFFER BOUNDS AGAINST MAX EQU CONSTANTS
- CONFIRM FIXED POINT ARITHMETIC AND SEGMENT STRIDE
- CONFIRM EVERY EXIT PATH RESTORES THE TERMINAL
- BUILD AND RUN BEFORE CLAIMING CORRECTNESS
